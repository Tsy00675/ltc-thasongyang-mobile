⚙️ เชื่อมต่อ Google Apps Script API

วางลิงก์ Web App URL จาก Google Apps Script (ลงท้ายด้วย /exec) เพื่อให้แอปนี้ซิงค์ข้อมูลกับ Google Sheet อัตโนมัติ

📱 วิธีติดตั้งเป็นแอปบนมือถือ (PWA)
• iPhone (Safari): กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรชี้ขึ้น) → เลือก "เพิ่มไปยังหน้าจอโฮม"
• Android (Chrome): กดจุด 3 จุดมุมขวาบน → เลือก "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"
